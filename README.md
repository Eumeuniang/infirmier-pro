# Infirmier Pro

Créer la plateforme SSMSI (Système de Suivi Médico-Professionnel et de Surveillance Sanitaire de l'Infirmerie). Implémenter le MVP complet : authentification avec sélection de rôle (Administrateur, Infirmier, Médecin du travail, Responsable QHSE, Direction), gestion CRUD des travailleurs (matricule unique, service, fonction, statut), module de consultation infirmière rapide avec référentiel de diagnostics catégorisés, gravité, prescription et suite donnée, dossier individuel du travailleur avec historique chronologique et timeline, et tableau de bord principal avec indicateurs clés (consultations, pathologies fréquentes, alertes, graphiques interactifs de tendances et répartition par service). Interface professionnelle et épurée en français avec jeu de données de test complet.
